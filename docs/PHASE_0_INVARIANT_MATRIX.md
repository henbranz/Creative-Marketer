# Phase-0 Invariant Matrix

Status meanings: `TESTED` means an automated gate exercises the enforcement; `ENFORCED` means the
control exists but its production integration is outside the current executable surface;
`DEFERRED` means a required later decision/control has an explicit trigger; and
`NOT_APPLICABLE_YET` means the protected product surface does not exist. Test paths are relative to
`apps/api` unless stated otherwise.
