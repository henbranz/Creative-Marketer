# 00 — Product Vision

## Product

**Creative Marketer — AI Creative & Growth Operating System for product founders**

A founder should be able to onboard a product once and then operate a continuously improving system that researches the market, generates creative hypotheses, produces content, publishes experiments, observes commercial outcomes, and learns what to do next.

## User Promise

The platform should answer:

- What should I create next?
- Why does the system believe it can work?
- What assets are missing?
- What was generated?
- What was published, where, and when?
- What did every agent do?
- What results came back?
- What changed in the system's understanding?
- Which actions require my approval?
- Can I take control at any time?

## Closed Loop

```text
Product Onboarding
      ↓
Research
      ↓
Creative Strategy
      ↓
Production
      ↓
Approval
      ↓
Publishing / Experimentation
      ↓
Traffic / Engagement / Orders
      ↓
Measurement
      ↓
Intelligence
      ↓
Updated Research / Strategy
```

## Initial Target User

Founder / small product team that:

- owns a physical product or catalog
- sells through Shopify or similar commerce
- needs frequent social creative
- cannot employ a full creative/research/marketing/operations team
- wants visibility and control rather than opaque autonomy

## Long-Term Expansion

Possible future agents/modules:

- Paid Ads Agent
- Email / CRM Agent
- SEO Agent
- Customer Support Agent
- Marketplace Agent
- Finance Agent
- Forecasting Agent
- Product Opportunity Agent
- Amazon/Etsy/eBay integrations

The architecture must permit expansion without giving existing agents new implicit privileges.

## Product Principles

### 1. User stays in control
The user can inspect, approve, reject, pause, override, and edit work.

### 2. Explainable operation
The system reports what each agent did, what evidence it used, what tools it called, and what results followed.

### 3. Evidence over vibes
Creative concepts include hypotheses. Insights include evidence and confidence.

### 4. Safe autonomy
Autonomy is permissioned per action category, not a global “AI on/off” toggle.

### 5. Replaceable providers
Model/provider quality changes quickly. Core product value cannot depend on one vendor.

### 6. Learning is scoped
What works for one product/channel/audience/time window must not automatically become a global rule.

## MVP Thesis

The first proof of value is not “manage the entire business.”

It is:

> **Autonomous Creative Loop:** product → research → concepts → media → publish → measure → learn → next concepts.

Commerce operations should be architected early but implemented after the creative loop demonstrates value.
