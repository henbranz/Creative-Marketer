# 10 — MVP Roadmap

## Phase 0 — Foundation

Build platform primitives only.

Deliverables:
- repo structure
- config/env strategy
- DB baseline
- tenancy
- users/memberships
- agent registry
- tool registry
- permission engine
- approval primitives
- audit
- events
- security primitives
- tests
- observability

## Phase 1 — Product Brain

- Product Digital Twin
- Brand profile
- claim policies
- audience
- Asset Library
- product onboarding UI/API

## Phase 2 — Research

- Research Snapshot schema
- evidence ingestion
- source provenance
- TTL/refresh rules
- competitor/trend research
- initial Researcher

## Phase 3 — Creative Strategy

- CreativeConcept schema
- hypothesis framework
- script/shot/CTA variants
- approval UI
- versioning
- first Creative Strategist

## Phase 4 — Production

- ProductionPlan
- asset requirement workflow
- provider-neutral media interfaces
- first image/video providers
- 9:16 + 1:1 output strategy
- QA and lineage

## Phase 5 — Publishing

- Instagram connector
- TikTok connector
- scheduler
- approval policy
- captions/links/UTMs
- publication audit

## Phase 6 — Measurement

- social metrics
- Shopify traffic/order linkage where possible
- experiment views
- attribution model with explicit uncertainty
- performance dashboards

## Phase 7 — Intelligence

- Insight schema/lifecycle
- evidence aggregation
- confidence/scope
- creative feature extraction
- revalidation/expiry
- next-experiment recommendations

## Phase 8 — Commerce Operations

- Shopify webhooks
- orders
- inventory
- production requirement
- fulfillment/shipping tracking
- Google Sheets sync/export
- invoice/document tracking architecture

## Phase 9 — SaaS Hardening

- billing
- usage limits
- organization/admin controls
- tenant onboarding
- provider quotas
- data retention controls
- export/delete
- security review
- scalability testing

## MVP Success Criterion

Do not judge the MVP by number of agents.

Judge whether the closed loop consistently helps a founder create and test better organic creative with less manual work while preserving control and visibility.
